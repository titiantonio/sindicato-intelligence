# Actualizacion de AGENTS.md para control con Documento 31

## Fecha

2026-06-05

## Objetivo

Incorporar en `AGENTS.md` la obligacion de usar el `Documento 31 - Plan de Implementacion Detallado` como backlog operativo del MVP y control de avance mediante checks en sprints, tareas y subtareas.

## Contexto

El usuario solicito que el agente siga el Documento 31 para controlar lo que debe implementarse y marcar como hecho lo ya realizado.

Antes de modificar se revisaron:

- `docs/00-agent-context.md`.
- `AGENTS.md`.
- `docs/Documentacion Proyecto/Documento 31 - Documento 31 – Plan de Implementación Detallado.md`.

## Archivos modificados

- `AGENTS.md`.
- `docs/Docs_Asistentes/2026_06_05_actualizacion_agents_documento_31.md`.

## Decisiones tomadas

- Se anadio el Documento 31 como documento especialmente relevante dentro de la documentacion obligatoria.
- Se definio el Documento 31 como backlog operativo y control vivo de avance.
- Se reforzo la seccion de orden de implementacion con reglas explicitas para localizar tarea antes de implementar y marcar con `✓` o `[x]` las tareas completadas.
- Se indico que los sprints o bloques superiores solo deben marcarse como completados cuando todas sus tareas verificables esten finalizadas.
- Se exigio registrar en la documentacion del asistente que tareas del Documento 31 se han completado o actualizado.

## Fase MVP relacionada

No aplica como implementacion funcional. Es una actualizacion documental transversal al control de avance del MVP definido en el Documento 30 y descompuesto en el Documento 31.
