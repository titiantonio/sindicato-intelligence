## Decisiones

- Se define `JwtTokenService` para generar access y refresh tokens con claims de usuario y rol.
- Access token con vencimiento en minutos y refresh token con vencimiento en dias, configurables por propiedades.
- Se agrega configuracion `app.security.jwt` en `application.yml`.
- Se configura `JwtEncoder` y `JwtDecoder` HS256 con validacion de secreto minimo de 32 bytes.
- Se incorporan logs operativos en emision de tokens sin exponer tokens ni secretos.
