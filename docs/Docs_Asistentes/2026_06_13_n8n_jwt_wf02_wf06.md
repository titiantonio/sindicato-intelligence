# Autenticacion JWT n8n WF-02 a WF-06

Fecha: 2026-06-13

## Objetivo

Alinear los workflows n8n restantes con la seguridad JWT del backend, usando el mismo patron ya aplicado en WF-01.

## Cambios realizados

- Anadido nodo `Authenticate Backend` en `WF-02-Classify-News`, `WF-03-Detect-Events`, `WF-04-Generate-Analysis`, `WF-05-Generate-Content` y `WF-06-Publish-Telegram`.
- Anadida cabecera `Authorization: Bearer` a todas las llamadas HTTP protegidas de WF-02..WF-06.
- WF-04..WF-06 mantienen el payload original del trigger tras autenticar mediante normalizadores que leen `Manual Trigger` o `Webhook Trigger`.
- Actualizados `versionId` de los workflows afectados a sufijo `-jwt`.

## Verificacion

- Validado JSON de `wf_01` a `wf_06` con `ConvertFrom-Json`.
- Verificado con `rg` que WF-02..WF-06 contienen `Authenticate Backend`, `auth/login`, `Authorization` y referencias `Bearer`.
