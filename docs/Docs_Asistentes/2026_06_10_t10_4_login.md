## Decisiones

- Login se implementa en caso de uso `LoginUseCase` con `AuthenticationManager` y credenciales email/password.
- En login exitoso se emiten access y refresh token mediante `JwtTokenService` y se devuelve `user.id`, `user.name` y `user.role`.
- En credenciales invalidas se responde `401` con mensaje estable `invalid credentials`.
- Se registran logs `INFO/WARN/ERROR` de login evitando contrasenas o tokens completos.
- Se desactiva `formLogin` y `httpBasic` para evitar comportamientos no deseados en API JWT.
